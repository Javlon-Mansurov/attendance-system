# Сравнительная матрица аналогов: ИС учёта рабочего времени (`attendance_db`)

**Цель:** сравнить существующие системы учёта рабочего времени (Time Tracking & Attendance) по ключевым критериям предприятия и определить, какие функции заимствовать в проект `attendance_db`.  
**Дата проверки данных:** 13.11.2026.

## 1. Критерии
| № | Критерий | Как оцениваем (шкала 0–2) | Вес |
|---|---|---|---|
| K1 | Отметка прихода/ухода (`check_in` / `check_out`) | 0 — нет / 1 — ручной ввод за месяц / 2 — фиксация в реальном времени | 3 |
| K2 | Индивидуальные графики работы по дням недели | 0 — нет / 1 — один общий график / 2 — настройка смен и перерывов для каждого сотрудника | 3 |
| K3 | Заявки на отпуск и учёт больничных/командировок | 0 — нет / 1 — только отпуска / 2 — отпуска с утверждением + больничные и командировки | 3 |
| K4 | Календарь государственных праздников | 0 — нет / 1 — ручное исключение / 2 — встроенный справочник праздников | 2 |
| K5 | Роль бухгалтера и выгрузка табеля | 0 — нет / 1 — просмотр списка / 2 — отдельная роль `accountant` и сводный отчёт | 2 |
| K6 | Русский интерфейс и локальная терминология | 0 — нет русского / 1 — частичный перевод / 2 — полноценный русский интерфейс | 2 |
| K7 | Стоимость владения для 60 сотрудников в год | 0 — дороже $1000/год / 1 — до $1000/год / 2 — бесплатно (open source / своя разработка) | 2 |
| K8 | Размещение на собственном сервере (on-premise) | 0 — только облако SaaS / 2 — установка на сервер предприятия | 2 |
| K9 | Скорость загрузки (PageSpeed Mobile) | 0 — < 50 / 1 — 50–89 / 2 — ≥ 90 | 1 |

## 5. Выводы
### Заимствуем
- **(K1)** Простой виджет фиксации начала (`check_in`) и окончания (`check_out`) рабочего дня в один клик, как в Битрикс24.
- **(K3, K4)** Разделение заявок на отпуск (`leave_requests`), документальных отсутствий (`absences`) и справочника праздников (`holidays`), как в OrangeHRM.
- **(K5)** Выделенную роль бухгалтера (`accountant`) для прямого доступа к сводному табелю без необходимости обращаться к HR.

### Не делаем
- Встроенный корпоративный мессенджер, видеозвонки и CRM-воронку продаж (избыточность Битрикс24).
- Интеграцию с биометрическими турникетами по аппаратным протоколам (вне рамок MVP).

### Наше отличие
- **(K7, K8)** Бесплатное развёртывание на локальном сервере предприятия (XAMPP / Linux VDS) без ежемесячной платы за каждого сотрудника.
- **(K6, K9)** Быстрый и понятный интерфейс на русском языке, адаптированный под структуру отделов и табельный учёт предприятия в Таджикистане.

**Позиционирование:** Для предприятий Таджикистана со штатом 30–100 человек, которым нужен точный табельный учёт рабочего времени, графиков смен и отпусков без дорогих облачных подписок, `attendance_db` — это лёгкая веб-ИС посещаемости с отдельной ролью бухгалтера, разворачиваемая на собственном сервере компании.
