# СУПОРИШИ ТЕХНИКӢ
**Барои коркарди веб-низоми «Баҳисобгирии вақти кории кормандон» (TimeTracker)**
*Мувофиқи талаботи ГОСТ 34.602-2020*

## 1. Муқаррароти умумӣ
* **Номи пурраи низом:** Веб-низоми автоматикунонидашудаи баҳисобгирии вақти кории кормандон (TimeTracker).
* **Фармоишгар:** Ширкат / Муассиса (Шӯъбаи кадрҳо ва роҳбарияти воҳидҳои сохторӣ).
* **Иҷрокунанда:** Донишҷӯи гурӯҳ (Коркардкунандаи веб-лоиҳа).
* **Мӯҳлатҳои иҷро:** Тибқи нақшаи таълимии фанни «Технологияҳо ва забонҳои Internet барномасозӣ» (Рӯзҳои 01–16).
* **Асос барои коркард:** Супориши таълимӣ ва супориши техникии кӯтоҳ (`docs/03-short-spec.md`).

## 2. Мақсадҳо ва таъиноти низом
* **Таъинот:** Автоматикунонии раванди сабти омадурафти кормандон, баҳисобгирии соатҳои корӣ, идоракунии ҷадвали корӣ, варақаи баҳисобгирӣ (табел) ва ба расмият даровардани рухсатиҳо ё бемориҳо.
* **Мақсадҳои ченшаванда:**
  1. Кам кардани вақти тартиб додани табели моҳонаи вақти корӣ аз 2 рӯзи корӣ то 5 дақиқа.
  2. Ба сифр расонидани хатогиҳои арифметикӣ ҳангоми ҳисобкунии соатҳои изофакорӣ ва таъхирҳо.
  3. Таъмини шаффофияти назорати интизоми меҳнат барои роҳбарони шӯъбаҳо дар вақти воқеӣ (на зиёда аз 2 сония таъхир).

## 3. Тавсифи объекти автоматикунонӣ
Объекти автоматикунонӣ шӯъбаи кадрҳо ва воҳидҳои сохтории корхона мебошад. Дар низом 4 гурӯҳи корбарон (акторҳо) фаъолият мекунанд (ниг. ба `docs/01-domain.md` ва `docs/02-matrix.md`):
1. **admin (Маъмури низом):** Идоракунии корбарон, нақшҳо, шӯъбаҳо ва танзимоти умумӣ.
2. **hr (Корманди шӯъбаи кадрҳо):** Назорати умумии табелҳо, тасдиқи ниҳоии рухсатиҳо, ташаккули ҳисоботҳои моҳона.
3. **manager (Роҳбари шӯъба):** Назорати ҳузури кормандони шӯъбаи худ, тасдиқи аввалияи аризаҳои рухсатӣ ва ислоҳи сабтҳои вақт.
4. **employee (Корманди оддӣ):** Сабти оғоз (Check-in) ва анҷоми (Check-out) рӯзи корӣ, дидани табели шахсӣ ва фиристодани аризаи рухсатӣ.

## 4. Талабот ба низом

### 4.1. Талабот ба низом дар маҷмӯъ (Талаботи ғайрифунксионалӣ — NFR)
* **NFR-01 (Меъморӣ):** Низом бояд дар асоси меъмории сесатҳа ва шаблони MVC (Model-View-Controller) бо истифода аз PHP ва MySQL коркард шавад.
* **NFR-02 (Иҷрогарӣ):** Вақти боркунии саҳифаи табели кормандон (то 50 сабт дар як саҳифа) ҳангоми мавҷудияти 1000 корманд дар пойгоҳи додаҳо набояд аз 0,5 сония зиёд бошад.
* **NFR-03 (Иҷрогарӣ):** Сабти омадурафт (Check-in / Check-out) бояд дар муддати на зиёда аз 0,3 сония коркард ва дар экран инъикос карда шавад.
* **NFR-04 (Эътимоднокӣ):** Нусхаи эҳтиётии (backup) пойгоҳи додаҳо бояд ба таври худкор ҳар 24 соат сохта шуда, на камтар аз 14 рӯз нигоҳ дошта шавад.
* **NFR-05 (Амният — Аутентификатсия):** Паролҳои корбарон дар пойгоҳи додаҳо бояд танҳо дар шакли рамзгузоришуда бо алгоритми `bcrypt` (`password_hash()`) нигоҳ дошта шаванд.
* **NFR-06 (Амният — Ҳифз аз ҳамлаҳо):** Ҳамаи дархостҳо ба пойгоҳи додаҳо бояд танҳо тавассути ифодаҳои омодашудаи PDO (Prepared Statements) иҷро шаванд; тамоми маълумоти баровардашаванда тавассути `htmlspecialchars()` экранонида шавад ва дар шаклҳо CSRF-токен истифода гардад.
* **NFR-07 (Мутобиқат):** Интерфейси низом бояд дар ду версияи охирини браузерҳои Google Chrome, Mozilla Firefox ва Microsoft Edge дуруст кор кунад ва ба экранҳои аз 360px (мобилӣ) то 1920px (десктоп) мутобиқ (responsive) бошад.
* **NFR-08 (Эргономика):** Сабти оғоз ё анҷоми кори корманд аз саҳифаи асосии кабинет набояд аз 1 клик зиёд вақт гирад; контрасти матн ва замина бояд на камтар аз 4,5:1 бошад.

### 4.3. Талабот ба намудҳои таъминот
* **Таъминоти иттилоотӣ:** Пойгоҳи додаҳои релятсионии MySQL (версияи 8.0+) бо кодировкаи `utf8mb4_unicode_ci`. Сохтори мантиқӣ ва физикӣ дар `docs/06-logical-db.md` ва `docs/07-physical-db.md` муайян шудааст.
* **Таъминоти лингвистӣ:** Интерфейси корбарӣ ба забони тоҷикӣ; коди барномавӣ, номи ҷадвалҳо ва сутунҳои ПД — ба забони англисӣ.
* **Таъминоти барномавӣ:** Сервери веб (Apache/Nginx), PHP 8.2+, СУБД MySQL 8.0+, Git.
* **Таъминоти техникӣ:** Сервери веб бо RAM на камтар аз 2 ГБ ва 10 ГБ фазои диск; компютер ё смартфони корбар бо дастрасӣ ба шабака.
* **Таъминоти ташкилӣ:** Таъини масъули пур кардани маълумотномаҳои аввалия пеш аз оғози кори низом.

## 5. Ҳайат ва мундариҷаи корҳо оид ба сохтани низом
1. **Марҳилаи 1 (Рӯзҳои 01–04):** Таҳлили соҳа, муқоисаи аналогҳо, таҳияи СТ-и кӯтоҳ ва диаграммаҳои UML.
2. **Марҳилаи 2 (Рӯзҳои 05–08):** Тарҳрезии меъморӣ, моделсозии мантиқӣ ва физикии ПД (`schema.sql`, `seed.sql`), таҳияи СТ-и пурра ва супоридани **Р-1**.
3. **Марҳилаи 3 (Рӯзҳои 09–12):** Барномасозии Backend ва Frontend.
4. **Марҳилаи 4 (Рӯзҳои 13–16):** Санҷиш (тестгузаронӣ), ислоҳи хатогиҳо ва ҳимояи лоиҳа (**Р-2**).

## 6. Тартиби коркард
* Ҳамаи коди сарчашма ва ҳуҷҷатҳо дар репозитории Git нигоҳ дошта мешаванд ва бо тегҳои `day-01` то `day-08` қайд карда мешаванд.
* Паёмҳои коммит ба рамзи талабот истинод мекунанд (масалан: `feat(FR-02): add check-in logic`).

## 7. Тартиби назорат ва қабули низом
* Қабули низом дар асоси санҷиши иҷрои 100%-и талаботи **Must** (`FR-01` то `FR-08`) тибқи сенарияҳои тестӣ (`docs/15-test-cases.md`) сурат мегирад.
* Скриптҳои `database/schema.sql` ва `database/seed.sql` бояд дар пойгоҳи додаҳои холӣ бе хатогӣ иҷро шаванд.

## 8. Талабот ба омодасозии объект барои ҷорӣ кардан
Пеш аз ба истифода додани низом, Фармоишгар вазифадор аст рӯйхати шӯъбаҳо, ҷадвалҳои корӣ ва кормандонро омода намояд.

## 9. Талабот ба ҳуҷҷатгузорӣ
Дар таркиби лоиҳа бояд `README.md`, папкаи `docs/` (`01-domain.md` то `15-test-cases.md`) ва папкаи `database/` (`schema.sql`, `seed.sql`) мавҷуд бошанд.
