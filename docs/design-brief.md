# Лабораторная работа 9. Дизайн в Figma — «Веб-приложение учёта рабочего времени сотрудников»

## 1. User flow (имена экранов = маршруты)

**Сценарий 1 — Отметка прихода и ухода (сотрудник)**
```
/login → / (дашборд) → [Отметить приход] → / (статус «На работе», время 08:57)
       → [Отметить уход] → / (сообщение «Рабочий день завершён: 8 ч 05 мин»)
```

**Сценарий 2 — Просмотр табеля и согласование (руководитель)**
```
/login → / → /timesheet (выбор месяца, отдела) → /employees/{id} (детали по сотруднику)
       → /leaves → [Согласовать] / [Отклонить] → /leaves («Заявка согласована»)
```

**Сценарий 3 — Заявка на отпуск (сотрудник)**
```
/login → / → /leaves → /leaves/create → [Отправить] → /leaves («Заявка отправлена»)
```

## 2. Вайрфреймы (Desktop 1440 × 1024, сетка 12 × 88, gutter 24)
1. `/login` — форма по центру (4 колонки): логин, пароль, «Войти».
2. `/` (дашборд) — шапка; карточки «Сегодня отработано», «Опоздания за месяц», «Отпуск (дней)»; кнопки «Отметить приход / уход»; последние 5 записей.
3. `/attendance` — слева 3 колонки фильтры (период, отдел, статус); справа 9 колонок: поиск, «Экспорт», таблица (дата, приход, уход, часов, статус), пагинация.
4. `/employees` — аналогично, карточки сотрудников (EmployeeCard).
5. (по желанию) `/timesheet`, `/employees/{id}`, `/leaves/create`, `/leaves`.

Реальные данные: «Рахимов Фарход Алиевич», «Заведующий кафедрой», «Кафедра программирования и ИС»; приход 08:57, уход 17:02; «Гуломов Джамшед», «Неъматов Бахтиёр».

## 3. Стили
Цвета и текст — см. `ui-kit.md` (8 цветовых стилей, 4 текстовых, Noto Sans).

## 4. Компоненты
- Button: Primary / Secondary / Danger × Default / Hover / Disabled, свойство Label.
- Input: Default / Focus / Error / Disabled; ошибка: «Время ухода раньше времени прихода».
- EmployeeCard на Auto Layout: фото, ФИО, должность, отдел, бейдж статуса («На работе», «Опоздал», «Отсутствует»).

## 5. Макеты
4+ экрана Desktop + 1 Mobile (iPhone 14, 390 × 844, 4 колонки, margin 16, gutter 16; фильтры над списком). Только экземпляры компонентов и стили.

## 6. Прототип
Поток «Отметка рабочего времени», стартовая точка — `/login`.
- «Войти» → `/` (Navigate to, Instant)
- «Отметить приход» → `/` в состоянии «На работе»
- меню «Журнал» → `/attendance`; «Сотрудники» → `/employees`
- карточка сотрудника → `/employees/{id}`; «Назад» → Back
- «Подать заявку» → `/leaves/create`; «Отправить» → overlay «Заявка отправлена» (Top center, Close when clicking outside)
