# Санҷишҳои кори лабораторӣ 13 — Баҳисобгирии вақти кории кормандон

| № | Амал / Санҷиш | Натиҷаи интизорӣ ва воқеӣ |
|---|---|---|
| 1 | `/work-logs` (саҳифаи 1) | 10 сатр намоиш дода мешавад, «Ёфт шуд: 28 сабт (Саҳифаи 1 аз 3)» |
| 2 | `/work-logs?page=3` ва `?page=99` | Дар саҳифаи 3 — 8 сатри охирин; ҳангоми `page=99` ба саҳифаи 3 (охирин) маҳдуд мешавад, бе хато |
| 3 | Филтр: Намуди рӯз «Иловакорӣ» + Шӯъба «Шӯъбаи барномасозӣ» | «Ёфт шуд: 2 сабт»; пайвандҳои саҳифабандӣ филтрҳоро нигоҳ медоранд |
| 4 | Ҷустуҷӯи «раҳ» | «Ёфт шуд: 7 сабт», аз ҷумла Раҳимов Ф.К. ва Абдураҳимова М.С. (utf8mb4_unicode_ci) |
| 5 | Ҷустуҷӯи `100%` (санҷиши экранкунии LIKE) | «Ёфт шуд: 1 сабт» (танҳо сабте, ки дар эзоҳаш `100%` дорад), на ҳамаи 28 сабт |
| 6 | Ҷустуҷӯи `OR 1=1` (SQL-инъексия) | «Ёфт шуд: 0 сабт», ягон хатои SQL ё дастрасии беиҷозат рух намедиҳад |
| 7 | Илова кардан бо санаи оянда (`2027-01-01`) ва вақти нодуруст | Рамзи HTTP 422, шакл бо додаҳои воридшуда ва паёми хато: «Санаи корӣ наметавонад дар оянда бошад» |
| 8 | Илова кардани сабти такрорӣ (ҳамон корманд + ҳамон сана) | Рамзи HTTP 422, санҷиши беназирӣ дар ПД: «Барои ин корманд дар ин сана аллакай сабти вақти корӣ мавҷуд аст» |
| 9 | Илова кардани сабти нави дуруст (POST `/work-logs/create`) | Равонакунии 302 (PRG) ба `/work-logs/29?msg=created` бо паёми «Сабти вақти корӣ бомуваффақият илова карда шуд» |
| 10 | Нест кардани корманди ID=1, ки сабтҳои вақти корӣ дорад | Хатои FK 1451 коркард мешавад, 302 ба `/work-logs?msg=fk_blocked` бо паёми фаҳмо (на саҳифаи 500) |
| 11 | Нест кардани сабти №29 (POST `/work-logs/29/delete`) | Равонакунии 302 ба `/work-logs?msg=deleted`, сабт нест мешавад |
| 12 | `/reports/hours` (Ҳисобот бо JOIN ва GROUP BY) | Ҷадвали ҷамъбастӣ аз рӯи 4 шӯъба: ҳамагӣ 8 корманд, 28 сабт, 212.00 соат, 3 рӯзи иловакорӣ, 1 ғоиб |
